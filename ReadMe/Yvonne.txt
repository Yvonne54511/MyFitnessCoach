    - Service: UserService (驗證帳密邏輯)

[] 註冊 (Register)
    - URL: /Auth/Register
    - Controller: UsersController
    - DTO: RegisterDto (Account, Password, Email, Name)
    - ViewModel: RegisterViewModel
    - Service: UserService (密碼雜湊加密、檢查帳號重複、建立會員邏輯)
    - Repository: UserRepository (Insert Users/Member)

[] 驗證 (Confirmation)
    - URL: /Auth/ActivateRegister
    - Controller: AuthController
    - Service: UserService (產生/驗證 Token、發送驗證郵件)
    - Repository: UserRepository (更新 EmailConfirmed 狀態)

[] 登出 (Logout)
    - URL: /Users/Logout
    - Controller: UsersController
    - Service: UserService (清除登入狀態 SignOut)

[] 修改密碼 (Change Password)
    - URL: /Users/ChangePassword
    - Controller: UsersController
    - DTO: ChangePasswordDto (OldPassword, NewPassword)
    - ViewModel: ChangePasswordViewModel
    - Service: UserService (驗證舊密碼、雜湊新密碼)
    - Repository: UserRepository (Update PasswordHash)

[] 忘記/重設密碼 (Forget / Reset Password)
    - URL: /Users/ForgotPassword, /Users/ResetPassword
    - Controller: UsersController
    - DTO: ResetPasswordDto
    - ViewModel: ForgotPasswordViewModel, ResetPasswordViewModel
    - Service: UserService (產生重設權杖、發送郵件、更新密碼)
    - Repository: UserRepository

[] 第三方登入 (External Login - Google)
    - URL: /Users/ExternalLogin, /Users/ExternalLoginCallback
    - Controller: UsersController
    - Service: UserService (OAuth 資訊處理、關聯現有帳號)
    - Repository: UserRepository / UserExternalLoginRepository

[] 用戶管理 - 列表 (View User List)
    - URL: /Users/Index
    - Controller: UsersController
    - ViewModel: IEnumerable<UserListViewModel>
    - Service: UserService (獲取分頁/篩選後的用戶列表)
    - Repository: UserRepository (Select Joined Roles)

[] 用戶管理 - 編輯 (Edit User)
    - URL: /Users/Edit/{id}
    - Controller: UsersController
    - DTO: UserEditDto
    - ViewModel: UserEditViewModel
    - Service: UserService (更新用戶基本資料與權限)
    - Repository: UserRepository (Update User)

[] 用戶管理 - 刪除 (Delete User)
    - URL: /Users/Delete/{id}
    - Controller: UsersController
    - Service: UserService (執行刪除或軟刪除邏輯)
    - Repository: UserRepository (Delete User)

[] Cookies / Middleware
    - 授權與身分驗證 (Authentication/Authorization)
