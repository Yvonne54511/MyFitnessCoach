=== (補充) 技術說明 ===

- ILogger<T>:
  * 用途: 內建日誌記錄工具，用於追蹤程式執行狀態或記錄錯誤。
  * 範例: 在 Service 中捕捉 Exception 後，使用 _logger.LogError(ex, "Message") 記錄錯誤詳細資訊。

- PasswordHasher<User>:
  * 用途: 安全地處理密碼雜湊與驗證，符合資安標準(不存明文)。
  * 非靜態類別，需實例化後使用。
  * HashPassword(): 用於將新密碼轉為雜湊值(如重設密碼時)。
  * VerifyHashedPassword(): 用於登入時比對明文密碼與資料庫中的雜湊值是否相符。

-IPasswordHasher<User>:DI注入介面，可用來單元測試時增加假的雜湊方法。

   .AsNoTracking()
